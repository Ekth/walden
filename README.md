# Walden Ekth — Mini site statique

Ceci est un petit site statique HTML/CSS qui met en valeur le génie "Walden Ekth".

Fichiers créés :

- `index.html` — page principale
- `css/styles.css` — styles

Comment voir le site localement :

1. Ouvrir l'explorateur de fichiers et naviguer vers le dossier `c:\Users\ekthw\Downloads\walden`.
2. Double-cliquer sur `index.html` pour l'ouvrir dans votre navigateur préféré.

Remarques / améliorations possibles :

- Ajouter des images réelles dans un dossier `assets/images/` et remplacer les placeholders.
